# Tienda Zapateria Jacinta - Evaluación Formativa 1

## Descripción del Proyecto
Este proyecto consiste en el desarrollo del sistema frontend de registro e interacción para una tienda de zapatos en línea. La solución busca ofrecer una buena experiencia a la navegación del usuario mediante una interfaz moderna e interactiva, garantizando además la correcta validación de datos.
